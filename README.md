# Dexcom-glucosescherm: firmware

Deze repo bevat alleen de **firmwarebestanden** (onder *Releases*) voor het Dexcom-glucosescherm op een Waveshare ESP32-C6-LCD-1.47. De broncode staat in een privé-repo.

Elke release bevat:

- `firmware.bin`: de firmware
- `firmware.bin.sha256`: het controlegetal (SHA-256) van de firmware

Het scherm kijkt zelf dagelijks of er een nieuwe release is. Op de instelpagina van het scherm kies je zelf of je hem installeert.
